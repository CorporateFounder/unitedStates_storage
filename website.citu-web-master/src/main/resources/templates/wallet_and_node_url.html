Exchange / Operator API Documentation

Pre-activation notice

V35 is prepared but not active yet. Exchanges and operators must wait for the final tagged release, final checksums, and official deployment notice.

The final production endpoint will be announced with the final release. Local smoke examples use http://localhost:8083 for the node and http://localhost:8082 for the wallet.

No founder burn has occurred until an official burn transaction hash and burn block are published.

Security boundary

Never place private keys or passwords in production URLs, logs, screenshots, support messages, or exchange integration scripts.

Wallet /keys and /sendCoin?...&password=... are legacy local-only surfaces. They are not production exchange integration endpoints.

Exchanges should use public read-only node endpoints and submit reviewed signed transaction JSON only through POST /addTransaction.

Node API: status and height

  • GET /size - blockchain size. Example: http://localhost:8083/size
  • GET /status - node status.
  • GET /confirmReadiness - readiness state: ready or not_ready.
  • GET /version - node version.
  • GET /datashort - compact blockchain metadata.
  • GET /prevBlock - latest block JSON.

Node API: blocks and balances

  • GET /conductorBlock?index=<INDEX> - block lookup by index.
  • POST /sub-blocks - bounded range lookup. Body: {"start":0,"finish":10}
  • GET /blockHash?hash=<HASH> - block lookup by hash.
  • GET /account?address=<PUBLIC_ADDRESS> - account balances.
  • GET /balance?address=<PUBLIC_ADDRESS> - balance snapshot.
  • GET /totalDollars - total GOLD supply under the legacy endpoint name.

Node API: transactions

  • GET /getTransactions - pending transaction list.
  • GET /senderTransactions?address=<ADDRESS>&from=0&to=10 - sent transactions.
  • GET /customerTransactions?address=<ADDRESS>&from=0&to=10 - received transactions.
  • POST /statusTransaction58 - Base58 signature status. Body: {"sign":"<BASE58_SIGNATURE>"}
  • POST /statusTransaction64 - Base64 signature status. Body: {"sign":"<BASE64_SIGNATURE>"}
  • GET /isTransactionAdd?sign=<BASE58_SIGNATURE> - inclusion boolean.
  • POST /isTransactionAddBase64 - Base64 inclusion boolean.
  • POST /findBlocksFromSign58 and POST /findBlocksFromSign64 - find containing blocks.
  • POST /addTransaction - submit reviewed signed transaction JSON.

Wallet API: local-only surfaces

  • GET http://localhost:8082/keys - local key generation. Keep private output local.
  • GET http://localhost:8082/account?address=<PUBLIC_ADDRESS> - account view.
  • GET http://localhost:8082/dollar?address=<PUBLIC_ADDRESS> - GOLD balance.
  • GET http://localhost:8082/stock?address=<PUBLIC_ADDRESS> - stock balance.
  • GET http://localhost:8082/sendCoin?...&password=<PRIVATE_KEY> - legacy local-only send path. Do not use for production integration.
  • POST http://localhost:8082/isTransactionAddBase64 - local inclusion check.

V35 read-only API

These endpoints become production-relevant only after the reviewed V35 server build is deployed. V35 still remains inactive until the approved fork height.

  • GET /v35/protocol
  • GET /v35/supply
  • GET /v35/burn
  • GET /v35/founder
  • GET /v35/founder/burn-snapshot
  • GET /v35/jackpot/status
  • GET /v35/jackpot/periods
  • GET /v35/jackpot/history
