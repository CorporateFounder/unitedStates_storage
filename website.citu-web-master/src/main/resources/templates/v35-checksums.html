Verification steps / Проверка / 验证步骤

  1. Download artifacts only from the official release location.
  2. Download final SHA256SUMS.txt and SHA256SUMS.txt.sha256.
  3. Verify SHA256SUMS.txt using SHA256SUMS.txt.sha256.
  4. Verify each artifact SHA-256 hash against SHA256SUMS.txt.
  5. Confirm the final tag and exact fork height match the official notice.

Use only official final release artifacts and checksums. Do not use draft, dry-run, unsigned, or unverified artifacts.
