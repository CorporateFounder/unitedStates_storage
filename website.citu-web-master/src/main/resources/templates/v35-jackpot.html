No live winners are shown here before V35 activation. Winners will be shown after activation when protocol payout data exists.

Recommended node 1.0.17 / wallet 1.0.2 releases are published. Website/operator guide 1.0.9 contains the current Node 1.0.17 link update. Before block 514291, v35Active=false is expected.

Eligibility and randomness

  • Every V35 mined block is a jackpot ticket.
  • Winner is minerAddress of selected eligible block.
  • Sender addresses are never jackpot participants.
  • Randomness is deterministic and based on delayed future block hashes.
  • No manual winner selection is used.
