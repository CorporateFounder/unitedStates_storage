Credential safety

Address / login / public key can be public. You can use this value for receiving funds and for public account lookup.

Password / private key is secret. Never share it in screenshots, chats, support messages, public forms, URLs, or logs.

Save credentials offline in a safe place. If the password or private key is lost, account recovery may be impossible.

No CITU support channel should ask for your password or private key.
